# 👋 Hola, soy Jorge Delgado

Desarrollador de software enfocado en el ecosistema **móvil híbrido** (iOS + Android).
Fundador de **[IziCodes](https://izicodes.com)**, donde construyo aplicaciones que resuelven
problemas concretos: gestión de inventario, educación universitaria, entretenimiento
y herramientas para músicos.

Actualmente estudiando en la **UAJMS** y explorando IA local, apps offline y arquitecturas
multiplataforma.
